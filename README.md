# KM Beauty & Wellness Corporate Website

Bubble-bright multi-page corporate and commerce concept for KM Beauty & Wellness, Her Skin, and Nekothione.

## Preview

Run a local static server:

```bash
python3 -m http.server 3000
```

Then open `http://localhost:3000`.

Product mockups and corporate branding are concept treatments pending official high-resolution assets and finalized brand guidelines.
