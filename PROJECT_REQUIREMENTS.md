# KM Beauty and Wellness E-Commerce

## Scope

Customer-facing storefront for browsing, cart, checkout, account, campaigns, and order experience. This app should consume product, pricing, checkout, promotion, and order APIs from the future MedusaJS commerce backend.

## Visual Direction

Follow the approved Glowhouse ecommerce mockup from the older static build. Preserve the playful beauty-commerce feel: large product-led hero, flash sale section, best sellers grid, campaign feature, brand categories, and testimonial/social proof areas.

## Near-Term Build Order

1. Convert static product sections into reusable components.
2. Add Medusa product/catalog client layer.
3. Build cart drawer and checkout flow against Medusa.
4. Add customer account pages and order history.
5. Add campaign/collection pages backed by CMS content.
